What I've Built

توقع فئات أسعار Airbnb — نيويورك

Airbnb Price Category Predictor — NYC

تطوير نموذج ذكاء اصطناعي لتوقع فئات أسعار عقارات Airbnb في نيويورك مع واجهة تفاعلية.

An AI model to predict Airbnb price categories in New York City with an interactive UI.

PythonScikit-learn PandasStreamlitNumPy

قمنا بتطوير مشروع متكامل يهدف إلى تحليل بيانات عقارات Airbnb في مدينة نيويورك وتوقع الفئة السعرية المناسبة للعقار باستخدام تقنيات التعلم الآلي، مع توفير واجهة مستخدم تفاعلية وسهلة الاستخدام.

A complete project analyzing NYC Airbnb listings data and predicting the appropriate price category using Machine Learning, with an easy-to-use interactive interface.

أبرز المميزات:

Key Features:

  • معالجة وتنظيف أكثر من 48,000 سجل من بيانات نيويورك (NYC Airbnb Open Data 2019)
  • Processed and cleaned 48,000+ NYC Airbnb records (Open Data 2019)
  • نموذج تصنيف دقيق لتحديد فئة السعر مع نسبة الثقة (Confidence Score)
  • Accurate classification model with Confidence Score
  • واجهة Streamlit خفيفة وسريعة للتنبؤ الفوري
  • Lightweight Streamlit UI for instant predictions
  • بنية برمجية منظمة وموثقة لسهولة التطوير مستقبلاً
  • Organized and documented code structure for future development
